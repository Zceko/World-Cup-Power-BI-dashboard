World Cup Data Analysis Dashboard
About the Project

This project presents an interactive Power BI dashboard analyzing FIFA World Cup data across different tournaments and countries.

Analysis
The dashboard includes the following analyses:

- Attendance by Country and Year – Analysis of World Cup attendance by country and tournament year.
- Countries Qualified for the World Cup – Overview of countries that qualified for the World Cup.
- World Cup Winners – Analysis of World Cup winning teams.
- Countries That Hosted the World Cup – Overview of host countries across different tournaments.
- Competition Statistics by Year – Comparison of key World Cup competition statistics over the years.

Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

Dashboard
The dashboard provides interactive visualizations that allow users to explore World Cup data by year, country, and competition statistics.
